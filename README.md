Build a household budget site, original and working, that runs offline in a web browser on a desktop and on a phone from its own files; an AI judge compares the sites two at a time, places go by win rate, and the 10 best share $50; the board's top 10 sites are open on makefun.gg.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
